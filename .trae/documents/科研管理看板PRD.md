## 二、产品概述

### 2.1 看板定位

技术科研管理看板是营收看板系统的核心子看板之一，面向企业技术管理与科研管理人员，提供施工方案审批、知识库使用、科研项目、科研成果、科研费用管控等多维度的数据可视化展示与分析能力。

### 2.2 目标用户

| 角色 | 关注重点 |
|------|----------|
| 技术管理负责人 | 审批完成率、方案退回率、交底完成率 |
| 科研管理负责人 | 科研项目分布、成果产出、费用管控 |
| 基层单位管理者 | 本单位科研数据对比 |
| 企业领导层 | 全局技术科研概览、费用达标情况 |

### 2.3 核心价值

- 将分散在多个业务系统中的技术科研数据整合到一个看板
- 通过图表可视化呈现，便于领导快速浏览
- 支持点击下钻到外部业务系统查看明细

### 4.6 科研费用管控

#### 4.6.1 功能描述

以"双柱+计划指标线"的方式展示各基层单位的科研费用（专项/配套）实际完成值与计划值的对比，支持季度切换，悬浮显示完成率与偏差。

#### 4.6.2 布局

整行满宽展示，包含：
- 季度选择器（Q1/Q2/Q3/Q4）
- 图例（专项实际、配套实际、计划指标线、未达标弱化）
- 图表区域（高度 380px）

#### 4.6.3 图表配置

| 配置项 | 值 |
|--------|-----|
| 图表类型 | 双柱状图（bar）+ 自定义系列（custom）水平计划线 |
| 柱宽 | 20px |
| 柱间距 | `barGap: '30%'` |
| 专项颜色 | 达标 `#3b82f6`，未达标 `#bfdbfe` |
| 配套颜色 | 达标 `#10b981`，未达标 `#a7f3d0` |
| 计划线颜色 | `#f59e0b`（橙），线宽 2 |
| tooltip | `trigger: 'axis'`，shadow 指针，自定义 formatter |
| 柱顶标签 | 不显示（`show: false`） |
| Y 轴 | 名称"万元"，隐藏轴线，虚线网格 |
| X 轴标签 | 旋转 25°，字号 10 |

#### 4.6.4 计划线绘制原理

使用 ECharts `custom` 系列的 `renderItem` 为每根柱子绘制一条水平线段：
- 数据格式：`[类别索引, 计划值, 侧别]`，侧别 `-1` 为专项（左柱），`+1` 为配套（右柱）
- 偏移量：`offset = 13 * side`（基于 barWidth=20, barGap=30% 计算）
- 线段半宽：10px（等于柱宽一半）
- Y 坐标：通过 `api.coord([类别索引, 计划值])` 转换

#### 4.6.5 颜色判定逻辑

| 条件 | 柱体颜色 | 含义 |
|------|----------|------|
| 完成率 ≥ 100%（actual/plan ≥ 1） | 主色（专项蓝/配套绿） | 达标，柱体突出显示 |
| 完成率 < 100% | 弱化色（浅蓝/浅绿） | 未达标，柱体弱化 |

#### 4.6.6 tooltip 内容

悬浮时同时展示该基层单位的专项和配套数据：

```
管网事业部
--- 专项 ---
计划值：60万
实际值：54万
完成率：90%（红色）
偏差：-6万（红色）
--- 配套 ---
计划值：40万
实际值：44万
完成率：110%（绿色）
偏差：+4万（绿色）
```

颜色规则：
- 完成率 ≥ 100%：`#10b981`（绿）
- 完成率 < 100%：`#ef4444`（红）
- 偏差 ≥ 0：`#10b981`（绿）
- 偏差 < 0：`#ef4444`（红）

#### 4.6.7 数据结构

```js
expenses: {
  quarters: ['Q1', 'Q2', 'Q3', 'Q4'],
  byCompany: {
    Q1: [
      {
        name: '管网事业部',
        special: { plan: 60, actual: 54 },
        supporting: { plan: 40, actual: 44 }
      },
      // ... 共 9 家单位
    ],
    // Q2, Q3 结构相同
    Q4: [
      {
        name: '管网事业部',
        special: { plan: 68, actual: 0 },   // Q4 actual 全部为 0（未开工）
        supporting: { plan: 44, actual: 0 }
      },
      // ...
    ]
  }
}
```

| 操作 | 行为 |

| 悬浮柱列 | 显示 tooltip（专项+配套的计划值/实际值/完成率/偏差） |

## 五、非功能需求

### 5.1 性能

| 项目 | 要求 |
|------|------|
| 图表初始化 | `onMounted` 后延迟 100ms 初始化（确保 DOM 渲染完成） |
| 图表更新 | Tab/维度/季度切换时实时更新，无加载延迟 |
| 窗口缩放 | 监听 `resize` 事件，所有图表自适应调整 |
| 资源释放 | `onUnmounted` 时 dispose 所有 ECharts 实例 |

### 5.2 兼容性

- 支持 Chrome、Edge、Firefox 等主流浏览器
- ECharts 5.x
- Vue 3 (`<script setup>`)
- Tailwind CSS

### 5.3 安全

- 外部 URL 基础地址通过环境变量 `VITE_SMART_WORKSITE_URL` 配置
- Demo 环境（URL 为空）下点击跳转显示提示文字，不实际跳转
- `openExternal()` 函数统一处理跳转逻辑
