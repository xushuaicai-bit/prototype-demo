## 二、模块概述

财务模块包含 5 张报表，从业财底账明细到按状态/基层单位/板块/销项四维度汇总，覆盖营收、利润、成本、资金全链路财务数据。

| 分区     | 报表名称       | 组件                                 | 核心特征                       |
| ------ | ---------- | ---------------------------------- | -------------------------- |
| 财务报表-1 | 业财统计报表     | `FinanceReport.vue`                | 底账明细，50+字段，版本管理，三色预警，自定义字段 |
| 财务报表-2 | 按项目状态分类汇总表 | `ProjectStatusSummary.vue`         | 按项目状态+结算状态汇总               |
| 财务报表-3 | 按分公司分类报表   | `BranchReport.vue`                 | 按基层单位×项目类型，含小计/合计/项目类型汇总   |
| 财务报表-4 | 按项目板块汇总表   | `SectorBusinessFinanceSummary.vue` | 按城市环境一/二/三级分类，含小计行         |
| 财务报表-5 | 销项项目汇总     | `OutputProjectSummary.vue`         | 销项项目经营分析，含利润偏差下钻           |

## 八、数据赋值规则说明

### 8.1 数据来源分类

| 来源类型         | 说明                     | 涉及报表            |
| ------------ | ---------------------- | --------------- |
| 前端 Mock      | 前端硬编码/随机生成的演示数据        | 全部报表            |
| 用户输入         | 用户通过筛选条件输入             | 全部报表筛选区         |
| 系统计算         | 通过 computed 属性聚合/派生的数据 | 全部报表汇总行/指标卡/小计行 |
| localStorage | 本地存储的筛选方案、导入版本         | 板块汇总表、销项汇总、业财统计 |
| 用户上传         | 用户导入的 Excel 文件         | 业财统计报表          |

### 8.2 计算规则汇总

| 计算类型 | 公式                                     | 应用场景                     |
| ---- | -------------------------------------- | ------------------------ |
| 求和   | `data.reduce((sum,i)=>sum+i[field],0)` | 各报表汇总行、小计行、指标卡           |
| 加权平均 | `Σ(值×权重)/Σ权重`                          | 平均利润率（按 projectCount 加权） |
| 派生计算 | `剩余计划 × 平均利润率 / 100`                   | 剩余计划毛利                   |
| 差值计算 | `已开票 - 已收款`                            | 未收款额                     |
| 毛利率  | `总毛利 / 总合同金额 × 100`                    | 已完工程毛利率                  |
| 预警判定 | 红色=竣工未送审；蓝色=储备<0或营收=0；黄色=营收>0          | 业财统计三色预警                 |

### 8.3 字段来源说明

* 当前所有报表数据均为前端 Mock（`generateMockData` 随机生成或硬编码常量）

* 业财统计报表支持用户导入 Excel 覆盖 Mock 数据，并留存版本

* 筛选方案存储于 localStorage，键名分别为 `outputProjectSchemes`（销项汇总）等
