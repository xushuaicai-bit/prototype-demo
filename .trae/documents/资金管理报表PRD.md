## 二、产品概述

### 2.1 产品定位

资金管理模块是营收看板系统的核心业务报表模块之一，面向企业财务、经营管理人员，提供从业财底账数据到多维度汇总分析的全套报表体系，支撑营收、利润、成本、资金的多视角分析决策。

### 2.2 目标用户

| 角色 | 关注重点 |
|------|----------|
| 财务管理负责人 | 业财底账数据、按基层单位/板块/状态的汇总分析 |
| 经营管理人员 | 项目利润率偏差、销项项目经营分析、合同完成情况 |
| 基层单位管理者 | 本单位营收、成本、资金汇总数据 |
| 企业领导层 | 全局营收完成率、利润达标情况、资金回笼情况 |

### 2.3 核心价值

- 业财统计报表作为底账，支持50+字段的明细查询与导入版本管理
- 4张汇总报表分别从项目状态、基层单位、项目板块、销项项目四个维度进行聚合分析
- 全报表支持多选筛选、保存筛选方案、导出Excel

### 2.4 报表清单

| 序号 | 报表名称 | 组件文件 | 数据维度 |
|------|----------|----------|----------|
| 1 | 业财统计报表 | `FinanceReport.vue` | 项目明细（底账） |
| 2 | 按项目状态分类汇总表 | `ProjectStatusSummary.vue` | 项目状态+结算状态 |
| 3 | 按分公司分类报表 | `BranchReport.vue` | 基层单位+项目类型 |
| 4 | 按项目板块汇总表 | `SectorBusinessFinanceSummary.vue` | 城市环境一/二/三级分类 |
| 5 | 销项项目汇总 | `OutputProjectSummary.vue` | 销项项目经营分析 |

## 三、业财统计报表

**组件**：`src/components/fund/FinanceReport.vue`

### 3.1 功能描述

业财底账明细报表，包含项目从合同信息到营收、利润、成本、资金的全生命周期财务数据。支持多条件筛选、数据导入版本管理、三色预警筛选、自定义字段显示、分类标签页切换。

### 3.2 筛选条件

| 筛选字段 | 类型 | 查询方式 | 选项/说明 |
|----------|------|----------|-----------|
| 生产项目编号 | 文本输入 | 精确查询 | - |
| 核算项目编号 | 文本输入 | 精确查询 | - |
| 项目名称 | 文本输入 | 模糊查询 | - |
| 基层单位 | 多选下拉 | 多选 | 城水管道、设备安装、二次养护、市政事业部、水建管道、运营养护、环境建设、区域发展 |
| 核算组织 | 文本输入 | 模糊查询 | - |
| 合同金额 | 文本输入 | 模糊查询 | - |
| 项目状态 | 单选下拉 | - | 待建、在建、停工、完工、竣工未送审、已送审、审定未销项、业务销项、财务销项 |

### 3.3 版本管理

#### 3.3.1 版本规则

- 每月留存版本以当月25号前手动导入的最后一版为准
- 顶部横幅展示当前生效版本信息（导入时间、数据条数）

#### 3.3.2 版本记录弹窗

| 操作 | 说明 |
|------|------|
| 查看版本列表 | 展示所有导入版本（导入时间、文件名、数据条数） |
| 留存版本标记 | 标识当前留存版本 |
| 恢复为此版本 | 切换到指定历史版本 |
| 当前生效标记 | 标识当前生效版本 |

## 八、通用规范

### 8.1 多选筛选规范

- 所有资金管理报表的基层单位、分类字段均支持多选
- 多选下拉支持"全选"选项，点击全选切换全选/取消全选
- 多选下拉使用 `collapse-tags` 折叠标签显示

### 8.2 筛选方案保存规范

- 按项目板块汇总表、销项项目汇总支持保存筛选方案
- 方案存储于 localStorage
- 支持方案重名覆盖

### 8.3 分类联动规范

- 一级分类变化时自动清理无效的二级、三级分类
- 二级分类变化时自动清理无效的三级分类

### 8.4 数据格式规范

| 数据类型 | 格式 |
|----------|------|
| 金额 | 千分位分隔，保留2位小数 |
| 百分比 | 保留2位小数 + % |
| 表头颜色 | #4a6fa5（深蓝） |
| 小计行背景 | 橙色 |

### 8.5 导出规范

| 报表 | 导出格式 |
|------|----------|
| 业财统计报表 | Excel（xlsx） |
| 按项目状态分类汇总表 | CSV |
| 按分公司分类报表 | CSV |
| 按项目板块汇总表 | Excel |
| 销项项目汇总 | Excel |
