## 二、模块概述

市场模块包含 1 个管理看板与 5 张明细报表，覆盖"市场跟踪→项目立项→投标→中标→合同签订"全链路。

| 分区     | 页面         | 组件                          |
| ------ | ---------- | --------------------------- |
| 市场管理看板 | 市场管理看板     | `MarketDashboard.vue`       |
| 市场报表-1 | 项目跟踪数据表    | `ProjectTrackingReport.vue` |
| 市场报表-2 | 重点跟踪项目清单   | `KeyProjectListReport.vue`  |
| 市场报表-3 | 城市环境投标情况汇总 | `BidSummaryReport.vue`      |
| 市场报表-4 | 中标项目清单     | `WinningBidReport.vue`      |
| 市场报表-5 | 在投项目清单     | `InBidReport.vue`           |
